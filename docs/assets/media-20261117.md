## Preparación y publicación

Extraer el ZIP y ejecutar con la cuenta de Cloudflare que contiene `levigno-assets`:

```sh
node scripts/prepare-media-20261117.mjs /ruta/a/Downloads '/ruta/a/6. AMENIDADES' --upload
npx wrangler d1 execute levigno-db --remote --file scripts/update-project-media-20261117.sql --yes
npm run offline:manifest
```

Aplicar el SQL únicamente después de subir todos los archivos. Los datos de portada e intro se configuran en `src/data/latest-media.ts`.
